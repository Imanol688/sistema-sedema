# SEDEMA v1.8.1 — Registro de clientes durante la venta

- CAJA y VENDEDOR pueden registrar y modificar clientes.
- Nuevo pedido incluye acceso directo “Registrar nuevo cliente”.
- Al guardar un cliente desde el pedido, el sistema vuelve al pedido y lo deja preseleccionado.
- Se mantienen tipos PARTICULAR, ALBAÑIL, EMPRESA, MAYORISTA y CONTRATISTA.
- No requiere cambios de base de datos.
